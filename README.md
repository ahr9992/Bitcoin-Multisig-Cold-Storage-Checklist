# Bitcoin Multisig Cold Storage Checklist | 比特币多重签名冷存储清单

> 2-of-3 multisig · Native SegWit (P2WSH) · No passphrase · Sparrow Wallet + 3 hardware wallets from different vendors.
>
> 一份可打印、可逐项打勾的比特币 2-of-3 多签冷存储操作清单，参照航空业"飞行前 / 飞行中 / 紧急情况"清单的写法编写。

## 为什么要写这份清单

2026 年 10 月，Ledger 硬件钱包被曝出**硬件供应链攻击**：设备在到达用户手中之前，被人在机壳内植入了一块带 LTE 蜂窝网络和 eSIM 的间谍电路板。用户一旦在设备上生成并显示助记词，植入物就会把助记词悄悄发给攻击者。链上研究机构估算的被盗金额约为 9,000 万美元以上，受害钱包超过 300 个。

这次事件说明了一件事：**只要你的全部资金依赖一台设备、一个品牌、一份助记词，任何一个环节出问题，就是全盘皆输。**

本清单要解决的就是这个"单点失败"问题：用 2-of-3 多重签名，把风险分散到三台**不同品牌**的设备上。即使其中一台被植入、被供应链污染或固件出漏洞，攻击者手里也只有三把密钥中的一把，仍然无法动用资金。

## Ledger 供应链攻击：来龙去脉

### 攻击是怎么实现的

| 环节 | 说明 |
|---|---|
| 植入位置 | 机壳内部，贴在屏幕数据线的测试点上。从外观上看不出任何异常，必须拆开设备才能发现。 |
| 植入物组成 | 微控制器、天线、LTE 物联网芯片和 eSIM。 |
| 窃取方式 | 不攻击安全芯片（Secure Element），而是**直接读取屏幕上显示的内容**，用光学识别还原出助记词，缓存后再通过 LTE 网络发给攻击者的服务器。 |
| 为什么能绕过检查 | 设备里的安全芯片是真的，所以电脑端的"正品验证（Genuine Check）"会显示通过。 |
| 攻击者何时动手 | 助记词外泄后，攻击者可以长期监控钱包，等到余额足够多时再一次性转走。 |
| 为什么屏幕会泄密 | 屏幕数据线上传输的是未加密的像素数据，目前连最高规格的设备也没有加密这条线路。因此凡是显示在屏幕上的内容，包括助记词和密码短语（Passphrase），植入物都能看到。 |

### 几个值得记住的事实

- **规模与专业程度**：从买下一家官方经销商、批量安装植入物，到使用全球物联网数据套餐回传数据，这是一次有组织、多代产品迭代的行动，而不是个人作案。
- **植入物"产品化"**：早期版本只是几根飞线，后来的版本做成了黑色、可卡扣固定，只需焊三个点。它可能是被卖给不同团伙使用的"犯罪工具"。
- **会越来越隐蔽**：今天打开机壳还能看出来；未来如果植入物做得更小，甚至藏进屏幕或电池里，肉眼将无法分辨。
- **不只是 Ledger 的问题**：Ledger 被盯上，是因为它是最大的品牌，而且部分型号外壳容易打开；任何品牌都需要更强的防拆设计和更可信的销售渠道。
- **Ledger 的建议**：购买自 CryptoBilis 的设备**不要初始化**；已经使用的，应把资产转到新设备并生成**全新的助记词**；只通过官方渠道购买；Ledger 不会主动联系你索要 24 个单词。

## 解决思路

### 1. 多重签名：消除单点失败

2-of-3 多签意味着需要三把密钥中的两把才能花钱。如果三把密钥来自**三个不同品牌、不同固件代码库**的设备，那么：

- 某一品牌被供应链污染、固件出漏洞、停止运营，只会影响其中一把密钥；
- 攻击者必须同时攻破至少两个互不相关的目标；
- 即使你不幸买到了被植入的设备，助记词外泄也只暴露一把密钥，资金仍然安全。

这正是本清单反复强调"三个不同品牌"的原因。

### 2. DIY：自己组装，从根上绕开供应链

供应链攻击的前提是"设备经过了别人的手"。DIY 的思路是用通用硬件自己组装签名设备，并使用开源固件，这样可以大幅降低被预先植入的风险。

### 3. 把操作写成清单，减少人为失误

多签方案比单签复杂：三把密钥、描述符、设备注册、地址核验、签名流程，任何一步出错都可能造成资金损失。所以我把完整流程写成了一份类似航空业标准的清单：每一步都有勾选框，关键位置有【危险】【注意】【中止条件】提示，遇到异常就停下，而不是凭感觉继续。

## 重要提醒

1. 清单是操作辅助工具，**不是安全保证**，也不能替代各品牌设备的官方使用手册。
2. 多签能大幅降低风险，但前提是**至少两把密钥不同时失守**。如果三台设备都买自同一个有问题的渠道，保护仍会被削弱。
3. 无论哪个品牌，凡是需要在屏幕上显示助记词的设备，都有被屏幕数据线上的植入物读取的理论风险。拆机检查、从官方渠道购买、使用防拆封包装，仍然是必要的基础动作。
4. 本清单假设读者已了解比特币托管的基本概念。第一次操作，请先用空钱包完整演练一遍，再考虑存入资金。
